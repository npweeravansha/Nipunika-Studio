11FAQ

Questions, answered.

A few things clients usually want to know before starting a project.

01What type of websites do you build?+

Nipunika Studio focuses on frontend websites such as landing pages, business websites, portfolio sites, service websites and other custom static website experiences.

02Do you provide backend development?+

No. The standard Nipunika Studio service is frontend development only. Backend systems, databases, authentication, admin panels and other server-side features are not included.

03How can I preview my website?+

A GitHub-based preview is provided so you can view the website, review progress and provide feedback before final delivery.

04Do I receive the source files?+

Yes. Once the project is completed and the final payment is settled, the final HTML, CSS and JavaScript source files are delivered.

05Do you provide hosting and domain setup?+

Domain and hosting charges are separate from the development package. If the website does not require a backend or database, Nipunika Studio can assist with domain setup, hosting and deployment.

06How much does a website cost?+

Packages start from LKR 9,000+. Business websites start from LKR 18,000+ and larger custom frontend projects start from LKR 30,000+. Final pricing depends on scope.

07How do I start a project?+

Send a message through WhatsApp or email with a short description of your project, the pages you need and any references you have. We can then discuss the requirements and next steps.
